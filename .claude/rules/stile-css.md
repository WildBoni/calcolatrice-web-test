Usa le variabili css per definire i colori, i font e le spaziature nel progetto.
Mantieni i nomi variabili coerenti e descrittivi, seguendo questa convenzione:
- Colori: --color-nome-colore
- Font: --font-nome-font
- Spaziature: --spacing-nome-spaziatura
Evita di usare valori hardcoded direttamente nei selettori.
